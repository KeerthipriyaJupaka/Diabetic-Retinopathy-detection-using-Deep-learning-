# Diabetic-Retinopathy-detection-using-Deep-learning-
Developed a deep learning-based system to detect and classify diabetic retinopathy from retinal fundus images using CNN, TensorFlow, and EfficientNetB0. Implemented image preprocessing and severity grading into five classes to support early detection and automated retinal image analysis.
# Diabetic Retinopathy Detection Using Deep Learning

## 📌 Project Overview
This project uses deep learning to detect and classify diabetic retinopathy from retinal fundus images. It uses CNN and EfficientNetB0 to identify five stages of diabetic retinopathy and support early screening.

## 🎯 Objectives
- Automate retinal image classification.
- Identify different severity levels of diabetic retinopathy.
- Explore deep learning techniques for medical image analysis.
- Provide predictions through a simple user interface.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Deep Learning:** CNN, EfficientNetB0
- **Frameworks:** TensorFlow, Keras
- **Image Processing:** NumPy, Pillow
- **Interface:** Gradio
- **Platform:** Google Colab

## 🩺 Classification Categories
1. DR
2. No DR
3. Mild
4. Severe

## ⚙️ Workflow
1. Upload a retinal fundus image.
2. Preprocess and resize the image.
3. Pass the image to the trained deep learning model.
4. Predict the disease severity category.
5. Display the predicted class and confidence score.

## 🚀 How to Run
1. Open the project notebook in Google Colab.
2. Install the required dependencies.
3. Load the trained model.
4. Run the notebook cells.
5. Launch the Gradio interface and upload a retinal image.
